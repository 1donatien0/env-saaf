# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private vulnerability reporting instead: open the repository's **Security** tab and choose **Report a vulnerability**. That creates a private advisory that only the maintainers can see.

You can expect an acknowledgement within a few days. When a fix is ready, the advisory is published together with the patched release, so users can see whether they were affected and which version to upgrade to.
